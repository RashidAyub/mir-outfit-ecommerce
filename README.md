# MIR OUTFIT — Premium Clothing E-Commerce Website

MIR OUTFIT is a premium fashion e-commerce storefront supporting both Summer and Winter collections, complete with real-time Firebase Authentication, Cloud Firestore, shopping cart, product details catalog, checkout functionality, and a dedicated administrator dashboard.

## Brand Identity
- **Brand Name**: MIR OUTFIT
- **Tagline**: Your Style. Every Season.
- **Color Aesthetics**: Black, white, beige, warm neutrals, elegant dark tones.

## Technical Stack
- HTML5, CSS3, Vanilla JavaScript (ES6+ Modules)
- Firebase Auth & Cloud Firestore (with local mock/localStorage fallback system)

## Folder Structure
- `/index.html` - Homepage
- `/shop.html` - Shop listing, filtering, search, and sorting
- `/product.html` - Product details & swatch selections
- `/cart.html` - Shopping cart management
- `/checkout.html` - Shipping/Billing collection and order generation
- `/order-success.html` - Order confirmation page
- `/login.html` & `/signup.html` - Customer access
- `/admin/` - Admin interface (Dashboard, Products CRUD, Orders)
- `/css/` - Styling sheets
- `/js/` - JavaScript ES modules
- `/assets/` - Images and icons
