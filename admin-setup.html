⚙️ Admin Account Setup

Use this page to grant admin role to an existing Firebase user. Run this once only. After setup, delete or restrict this page.

⚠️ Security Notice: This page writes to Firestore and should not be publicly accessible. Remove it from production after use.
Instructions:
  1. Make sure the user is already registered via the Signup page
  2. Enter that user's email below
  3. Enter the Firebase UID (find it in Firebase Console → Authentication)
  4. Click "Set Admin Role" — it will write role: "admin" to Firestore
  5. Log in with that account — it will now access the Admin Dashboard
